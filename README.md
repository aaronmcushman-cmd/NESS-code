# NESS-code
Code used for "The Development and Testing of Normed Entropic Slope Sensitivity: A Novel Information-Theoretic Metric for the Analysis of the Syntactic Dependence in Animal Communication"

Sperm whale data is available as part of https://doi.org/10.1038/s41467-024-47221-8
from https://github.com/pratyushasharma/sw-combinatoriality/tree/main/data

Other data is available as part of https://doi.org/10.1098/rspb.2014.1370

# Use
* Clone this repo
* Create a subdirectory data `md data`
* Copy the above mentioned data to that directory
** e.g. curl https://raw.githubusercontent.com/pratyushasharma/sw-combinatoriality/refs/heads/main/data/sperm-whale-dialogues.csv -o data/Sharma_et_al_2024_WhaleDialogues.csv
** Obtain the other data and place in data/ with file names as follows:

Kershenbaum_et_al_2014_Bat.csv
Kershenbaum_et_al_2014_Chickadee.csv
Kershenbaum_et_al_2014_English.csv
Kershenbaum_et_al_2014_Finch.csv
Kershenbaum_et_al_2014_Hyrax.csv
Kershenbaum_et_al_2014_Orangutan.csv
Kershenbaum_et_al_2014_Orca.csv
Kershenbaum_et_al_2014_Pilot.csv

* Load and execute  FinalCode.ipynb
